# Interview Guide

고3 담임 선생님을 위한 **학생부 기반 대입 면접 준비 프로그램**(Windows)입니다.

학생부를 올리면 이름·학교를 가린 뒤 역량 문장에 형광펜을 칠합니다. 그리고 문장마다 예상 질문, 대학별 면접 전략, 제시문, AI 모의면접, 인쇄 자료를 만들어 줍니다.

## 내려받기

[Releases](https://github.com/DylanM0/interviewguide/releases/latest)에서 `InterviewGuide-Setup-<버전>.exe`를 받아 실행하세요.

- 코드 서명이 없어서 처음에 Windows가 "PC 보호" 경고를 띄웁니다. **추가 정보 → 실행**을 누르세요.
- 새 버전이 나오면 프로그램이 알아서 받아 두고, 다시 시작할 때 적용합니다.

## AI 연결 (API 키 입력 없음)

- **구독**: 이미 쓰고 있는 Claude 구독(Claude Code) 또는 ChatGPT 구독(Codex)으로 분석합니다.
- **무료**: 구독이 없으면 OpenRouter(브라우저로 연결)나 Gemini 키로 쓸 수 있습니다.
- 원본 학생부와 녹음은 PC 밖으로 나가지 않습니다. 이름·학교를 가린 글만 연결한 AI에 보냅니다.

## 학생 연습 화면

선생님이 프로그램에서 [학생에게 보내기]를 누르면 링크가 만들어집니다. 학생은 휴대폰으로 그 링크를 열어 연습합니다.

- 문제지는 링크의 `#` 뒤에만 담깁니다. GitHub 서버로 전송되거나 저장되지 않습니다.
- 학생이 연습한 결과는 '결과 코드'로 선생님께 보내고, 선생님이 프로그램에 붙여 넣어 가져옵니다.

## 자료 출처

- 각 대학 2027학년도 수시 모집요강
- 대학별 2027 학생부종합전형 가이드북
- 대입 면접 후기·기출 모음(사용 허락을 받은 자료)

대학 면접 방식은 바뀔 수 있으니, 지원 전에 해당 대학 모집요강으로 꼭 확인하세요.
